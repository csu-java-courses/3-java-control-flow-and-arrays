# java-control-flow-and-arrays

Учебные задания по ветвлениям, циклам и массивам. Каждое задание — отдельный maven-модуль `taskNN`.

В каждом модуле:

* `README.md` — условие задания;
* `src/main/java/com/example/taskNN/TaskNNMain.java` — здесь пишется решение вместо заглушки с `//todo`;
* `src/test/java/com/example/taskNN/Tests.java` — тесты, проверяющие решение. Менять их не нужно.

## Сборка и запуск тестов

Нужны JDK 8+ и Maven 3.6+.

Проверить одно задание:

```
mvn -pl task01 test
```

Проверить все задания сразу (`-fae` — не останавливаться на первом упавшем модуле):

```
mvn -fae test
```

Пока метод не реализован, тесты задания падают — это нормально. Задание считается выполненным, когда `mvn -pl taskNN test` проходит успешно.
